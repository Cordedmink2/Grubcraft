# Grubcraft

A six-player LAN real-time strategy game where Warcraft III's base-building meets Shogun: Total War's regiment battles, fought over the corpse of a fallen god. Built on a lean custom engine for Mac and Windows, with a 6 GB memory budget for a full 6-player war.

- **Conquest** (main mode): gather Grub and Marrow, build a base, tech up, and command regiments with formations, flanks and morale. 2 to 6 players, 20 to 60 minutes.
- **Field Battle**: pre-built armies, one battlefield, 5 to 20 minutes.
- **Four factions** with four different economies: the Ember Clans, the Brood, the Choir and the Carrion Concord.

## Status

M0 (foundations) is done apart from a test run on a Windows PC. All eight M1 steps (regiments on a field) are built: formations, soldiers on screen, controls, melee and arrows, morale, pathfinding, the sandbox, real art and the Commander View, plus the menus and lobby screens. Golden replays (recorded battles that every change must still play exactly the same, on Mac, Windows and Linux) and the 6,000-soldier big-battle benchmark are in; what's left for the M1 exit is a 3,000-soldier, 60 fps check on real machines. M2 (LAN battle) has started: up to four machines on one network can play a Field Battle together (see Playing with friends below). Soldiers in the front rank pair off and duel, and blocks move like bodies, easing into step and swaying when they stand. Friendly blocks can push through each other, slowly, and fall into visible disorder while they do. The battle AI is in: you can fight computer opponents at four levels in a Field Battle from the lobby, or hand any sandbox side to the computer. The top level, the Warlord, reads your plan from how your army moves and rehearses its own plans in a copy of the real battle before choosing one. It reads the ground, anchoring its line on cliffs and waiting behind rivers, and `L` shows what it is thinking. The ground matters in a fight: regiments fighting downhill hit harder, archers on high ground shoot further, and regiments wading a ford are slow, can't charge and take heavier blows. In fords and passes, friendly regiments queue behind each other instead of piling into one lump. Weapons need the right formation: spears and pikes fight from two ranks and strike first, big swinging blades need room, and `R` (or `F`) switches a regiment between Line, Tight, Loose and (for shields) Shield wall. Woods and tall grass hide regiments: a hidden regiment that hits an enemy who hadn't seen it coming springs an ambush, and the computer players see only what their side sees and lay ambushes of their own ([20 · Ambushes](docs/20-ambushes.md)). See the [roadmap](docs/13-roadmap.md). Start with the [design documents](docs/README.md).

## Building and running

You need [Rust](https://rustup.rs) (stable). Then, from this folder:

```sh
cargo run --release -p gc_game          # play the current build
cargo test --workspace                  # all tests, including determinism
cargo run --release -p gc_bench         # simulation benchmark with budget checks
cargo run -p gc_bake                    # check data/*.ron and bake target/grubcraft.pak
cargo run --release -p gc_game --features profile   # build with Tracy profiling
./scripts/bundle-macos.sh               # macOS: build Grubcraft.app (universal) and zip it
```

**Menus:** the game opens on the main menu. **Sandbox** starts the battle below. **Play** lets you host a lobby (map, with **New map** for another and a map code to type in, mode, tempo, up to six players in six slots; add AI players and pick each one's level, Recruit, Veteran or General; pick faction, colour (Red, Violet, Cyan, Bone, Amber or Jade) and team, then Start) or join one: games hosted on your network show up in the Join list, or type the host's IP address (port 47820). Up to six machines can play together, with AI players filling any slot; the host's machine runs the AI. Start opens a **Field Battle**: every side gets ten regiments from its faction, set out on its own start plateau (you and your allies at the south, facing north; in a five- or six-player game of three teams with pairs in it, each team takes a column instead, yours at the west), and the computer players command theirs. The first side left holding the field for ten seconds wins (the panel says VICTORY or DEFEAT). The four factions are balanced for Field Battles: any pairing is close to an even fight. **Settings** holds your name, colour and faction, UI scale and the audio, graphics and accessibility choices (saved to a `settings.ron` file in your user config folder; only name, colour, faction and UI scale do anything yet). **Unit viewer** shows each unit and hero of the four factions as a 3D model on a plinth, with an orbit camera, a button for each animation and Stats and Abilities tabs.

**Playing with friends (LAN):** everyone runs the same build (the lobby shows each player's build and won't start until they match). One player chooses Play, then Host. The others choose Play and pick the game from "Games on your network", or type the host's IP address and press Join. On a Mac, allow Grubcraft to find devices on your local network and to accept incoming connections when macOS asks. Each joiner ticks Ready, the host adds AI players if wanted and presses Start. If someone's connection drops during the battle, the game pauses for up to 90 seconds while they come back (the host can press P to carry on without them); set **On drop** to Play on in the lobby to keep playing instead. The lag between giving an order and seeing it adjusts itself to the slowest connection. If the machines ever disagree about the battle, each one saves a desync report in a `desync-reports` folder next to its settings file; send those to the developers. If a game doesn't show up in the list, type the join code the host's lobby shows (like `K7QD-M2XA`) or the host's address; that usually still works (some Wi-Fi networks block the broadcast that finds games). The host can set a password on the Play screen; friends type it in the Password box. Everything sent between the machines is encrypted. From the terminal, `--host` opens a lobby straight away and `--join ADDRESS` (or a join code) joins one; add `--password WORD` for a locked lobby.

**Controls:** you are red. Left-click a red regiment to select it, or left-drag a box around several (a green rubber-band rectangle shows the box; Shift adds or removes). Right-click the ground to march the selection there side by side, facing the way they travel; right-drag to draw the line they should form instead (its length sets how wide they stand, and they face away from you). A big selection forms several lines. Right-click an enemy regiment to attack it. Your back two rows are Yumi archers, who shoot at enemies in range on their own; blocks that touch fight, and flank, rear and charging hits hurt more. Regiments that lose heart waver (a blinking amber banner), then rout (a white banner): they break ranks and run, ignoring orders, and rally once the enemy is gone; a regiment that routs twice is shattered (a grey banner) for good. Regiments in woods (dark green, with trees) or tall grass (pale tufts) are hidden from enemies who aren't close: a moss-green flag above one of yours means the enemy can't see it, and enemies you can't see aren't drawn. Charging out of hiding into an enemy that hadn't seen you springs an **ambush** (it loses a lot of morale and fights badly for a few seconds; an "AMBUSH!" message and a drum and horn tell both sides), and so does an archers' first ordered volley from hiding; hidden archers only shoot when you order them to. Woods also slow a march (cavalry and monsters most), and their trees catch some of the arrows shot into or out of them. In the sandbox **Shift+V** shows every regiment, hidden or not. The top bar's **Place** button (or **B**) opens the **Place panel**: a cloth with two tabs, **Field types** (Yari Ashigaru, Skitterlings, Shardlings, Bone Pikes, Yumi Ashigaru, each with its soldiers, speed and points) and **All factions** (a chip for each of the four factions, then every fighting troop of its roster with soldiers, speed and Grub and Marrow cost; workers and the Caravan are left out), and a row of the four sides. Click a troop to choose it and start placing, click a side to place for it, then left-click the field; picking a troop from the other tab starts the sandbox again on that unit table, clearing the field; **[** and **]** still step through the types. **K** lets you try buildings: it switches the click to placing the chosen building for the side you command (**[** and **]** choose which; a ghost shows whether it fits), **Delete** over a building takes it away, and right-clicking an enemy building with regiments selected sends them to knock it down. Buildings are plain boxes in their side's colour for now; they dim as they are damaged and show a bar over them, and they exist only in the sandbox. Regiments find their own way around cliffs and deep water: a selected regiment shows its route as a dotted line, and **G** shows the ground no regiment can cross. Ctrl (Cmd on a Mac) + a number key saves the selection as a control group; the number recalls it (Shift adds it), and pressing it twice centres the camera on it. The bar along the bottom has a **minimap** (click or drag to move the camera, right-click to send the selection there) and an **army tray** with a card for each selected regiment (click to select it alone, Shift-click to toggle, double-click to centre the camera on it). The **command grid** at the bar's right end has **Q** Move and **W** Attack (press, then left-click the ground or an enemy; Esc cancels), **R** Formation, **Z** Brace (spears and pikes only) and **V** Fall back; the other slots (Hold, Skirmish, Charge, Run and the abilities) are dimmed until those orders exist. When one of your regiments is losing men, is ambushed or breaks, and it is off screen, a badge on the screen edge points that way (a red `!`, an orange `A` or a pale `R`); click it or press **Space** to look there. The top bar names the mode, the side you command, the game speed and the clock, and has a **? Help** button; **H** or **F1** (or the button) opens the **Marshal's Scroll**, a list of every key in groups (Orders, View, Sandbox) with what the computer players are doing, and **Esc** or the same key closes it. The **Guide** (main menu, the top bar's **Guide** button, or **U**) lists every building and troop of the four factions, with its role, stats and upgrades. In a team match the top bar also has a **Hand over** button: it gives your whole army to your first living ally, who then commands it (click again for the next ally, and once more to take it back; its label shows who has it). Hover a command button for a moment to see its full name, key and what it does. With regiments selected the tray shows a banner in your colour with the regiment's name, soldier count and health and morale bars (in Conquest **F1** still finds an idle worker while one stands idle). Heroes are not in the game yet, but **Shift+H** previews the hero panel with a made-up hero. Pan with the arrow keys, screen edges or a two-finger trackpad scroll; zoom with the mouse wheel or a pinch; rotate with Alt + middle-drag, a two-finger twist, or the `,` and `.` keys; Home or a middle-click resets the rotation. The camera tilts with the zoom: about 55° from the default zoom out, easing down to 30° at the closest zoom, so close up you look more along the ground and see the sky. **F9** steps through the lighting looks (Noon, Golden hour, Overcast, Storm, Dusk; Golden hour is the default), and `--look NAME` (for example `--look storm`) opens with one. Marching soldiers kick up dust and arrows raise puffs where they land, and a charge that hits home rolls a cloud (the Graphics preset in Settings thins them: all on High, three quarters on Balanced, a third on Battery); `--fx-demo` sets off every effect (dust, smoke, fire, sparks, wounds, debris, ghost-light) in slow motion at the camera's focus, and `--fx-still` freezes them at several ages for a picture. With a regiment selected, **Y** puts the camera just above head height behind its rear ranks, looking where it faces, so you feel you are in the line (you can still select and give orders, and it works while you watch a replay); press **Y** or **Esc** again, or pan, zoom or rotate, to go back to the bird's-eye view. **`** (backquote) or **F11** shows the dev overlay with frame, tick and memory stats (and prints memory to the terminal); **Esc** returns to the map first while riding, otherwise opens the menu (Resume, Play, New sandbox, Settings, Exit). Start with `--overlay` to show it from the first frame, `--no-menu` to skip the main menu, or `--battle recruit|veteran|general|warlord` to go straight into a Field Battle against one computer player of that level. `--map ribcage_pass` or `--map four_teeth` (or `--map` with a map file's path) opens the sandbox on that map instead, to look round it. `--seed N` sets the map seed the Host a game card starts on, and the map a `--battle` is fought on.

**Computer players:** **I** hands the side you command to the computer (press again to step it up from Recruit to Veteran to General to Warlord, and once more to take the side back). The Marshal's Scroll (**H**, **F1** or the **? Help** button in the top bar) shows each computer player's personality, level, battle plan and what it expects ("Hold the line, advancing, expects a close fight"), and the latest thing it decided for the side you command. With Tab and I you can set two computer players against each other and watch.

To measure memory on your machine: `cargo run --release -p gc_game -- --frames 600` runs for 600 frames and prints the numbers. Measurement flags: `--latency 1|2|3` (frames in flight), `--render-scale 0.25..1` (render fewer pixels than the window has), `--draw all|terrain|blocks|none` (turn parts of the frame off), `--lod 0..3` (draw every soldier at one level of detail), `--showroom all|buildings|NAME[,NAME...]` (stand the named soldier models, as spelled in `assets-src/models.ron`, in a row on an empty field under a fixed camera, cycling through idle, walk, attack and death, to review them; `--showroom-clip idle|walk|attack|shoot|cheer|die` holds one clip instead; it does not combine with `--sandbox`, `--battle`, `--host` or `--join`), `--viewer NAME|start` (opens the Unit viewer, over the main menu, on the named unit or the first with a model; not with `--sandbox`, `--battle`, `--conquest`, `--host`, `--join` or `--showroom`), and `--no-shadows` and `--no-glow` (turn off the sun's shadows and the glow around bright light).

## Layout

| Path | What |
|---|---|
| `crates/gc_fixed` | Deterministic fixed-point maths (no floats) |
| `crates/gc_assets` | Asset pack format: writer and zero-copy reader |
| `crates/gc_data` | Game data tables (units, factions) as the game reads them |
| `crates/gc_sim` | The deterministic simulation; runs identically on every machine |
| `crates/gc_map` | Maps: the seeded battle generator, the RON map format and loader, and the terrain rules the game and `gc_mapcheck` share |
| `crates/gc_audio` | Sound: ADPCM bank, 32-voice mixer, lock-free command queue, `cpal` output |
| `crates/gc_platform` | Memory accounting and OS process stats |
| `crates/gc_render` | wgpu renderer (Metal, DirectX 12, Vulkan) |
| `crates/gc_ui` | Menus, lobby and settings screens, and the battle HUD's minimap and army tray (immediate-mode UI, no GPU code) |
| `crates/gc_net` | LAN play: UDP transport, finding games on the network, the lobby protocol and host-sequenced lockstep turns |
| `crates/gc_ai` | Computer players: battle tactics, difficulty levels and personalities; they read the sim and send ordinary commands |
| `crates/gc_game` | The game application |
| `tools/gc_bake` | Baker: compiles `data/*.ron` (and later art and audio) into the asset pack |
| `tools/gc_sfx` | Sound generator: synthesises the effects and music loops, and layers the battle cries from recorded voices, into `assets/audio/sounds.gcsnd` |
| `tools/gc_bench` | Headless benchmarks with budget gates |
| `tools/gc_mapcheck` | Map validator: `cargo run -p gc_mapcheck -- check` checks every map in `data/maps/` for validity and fairness; `png FILE OUT.png` draws one; `gen RECIPE SIZE SEED OUT.ron` writes a Field Battle or Conquest recipe map from a seed; `battle AREA ROUTE FEATURE fort\|open SEED OUT.ron` writes a campaign battle map |
| `assets/audio/` | The sound bank and its catalogue |
| `data/maps/` | The Conquest maps, as RON descriptions (Ribcage Pass, The Four Teeth) |
| `data/` | Game data in RON: edit these to change units, and `data/ai/` the computer players' personalities (rebuilt automatically) |
| `docs/` | Design documents |
