GRUBCRAFT for Windows
=====================

Starting the game
-----------------
1. Unzip the whole folder first. Do not run the game from inside the zip.
2. Open the Grubcraft folder and double-click grubcraft.exe.
Everything the game needs is inside grubcraft.exe. You can move the
folder anywhere.

"Windows protected your PC" (SmartScreen)
-----------------------------------------
Grubcraft is not signed by a big publisher, so Windows warns you the
first time. This is normal.
1. Click "More info".
2. Click "Run anyway".
Windows remembers your choice.

Allow Grubcraft through the firewall
------------------------------------
LAN games need this, or friends cannot find or join your game.
When Windows asks "Allow Grubcraft to communicate on these networks?":
1. Tick "Private networks".
2. Click "Allow access".
If you missed the question:
1. Open Start and type "Allow an app through Windows Firewall".
2. Click "Change settings", then find grubcraft (or "Grubcraft").
3. Tick "Private" for it, then click OK.
Your Wi-Fi must be set to a Private network. In Settings, open Network &
internet, open your Wi-Fi, and choose "Private network".

Hosting a game
--------------
1. In the main menu, click Play.
2. Under "Host a game", click Host.
3. The lobby shows your join code (like K7QD-M2XA) and your address.
   Friends on the same network will also see your game in their list.
4. When everyone is in, click Start.

Joining a game
--------------
1. In the main menu, click Play.
2. Under "Join a game", click your friend's game in the list.
   If it is not there, type their join code or address in the box.
3. Click Join.

Everyone must run the same version of Grubcraft. If the lobby says the
versions differ, get the same zip from the same person.

Playing over the internet needs a virtual LAN tool such as Tailscale or
ZeroTier. Then join by typing the host's address on that tool (the
join code shows the home network address, which friends elsewhere cannot reach).
